The actual contribution

The result that matters is protocol-level metadata persistence across tier eviction — not a new eviction-scoring algorithm. Scoring itself uses LRFU (Lee et al., 1999). What's new is keeping that metadata alive across a tier eviction event, which the persistent-metadata simulation demonstrates and which requires no CXL hardware to test.

No CXL hardware was tested in this package. No cost or TCO figure is provided.
